Where this record comes from
Windsor returns each entity's status at pull time and keeps no history, so this record is built by diffing consecutive snapshots. It can only see transitions that happened between two pulls: a campaign switched off and back on inside one hour is invisible to it. Lost delivery is hours off × that campaign's trailing average hourly spend before it stopped, so it is an estimate, not a billed figure.
